# Student_Score_Prediction_ML
This project is an end-to-end Machine Learning application that predicts a student’s math score based on demographic and academic features such as gender, parental education, lunch type, test preparation, reading score, and writing score.
The project demonstrates the complete ML lifecycle:

1.Problem framing

2.Data preprocessing

3.Model training

4.Model evaluation

5.Taking real-time user input

6.Generating predictions

It is built using Scikit-learn pipelines to ensure clean preprocessing and prevent data leakage.

Problem Statement:

Educational institutions often want to understand how different factors affect student performance.
The goal of this project is to predict a student’s math score using historical data and machine learning.

Dataset:
Dataset Name: Student Performance Dataset

Source: Kaggle / UCI Machine Learning Repository

Features Used:

1.gender

2.race/ethnicity

3.parental level of education

4.lunch

5.test preparation course

6.reading score

7.writing score

Target Variable:

1.math score
